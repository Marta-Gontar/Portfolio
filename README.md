## Project 1: Telegram боти і AI агенти
[Посилання](https://github.com/MartaHontar/N8N_project)

Розробила автоматизованого Telegram-бота на базі n8n з інтеграцією Groq LLaMA 3.3 70B для генерації структурованих статей українською мовою. Реалізувала багатоетапний процес модерації з інлайн-кнопками в Telegram для публікації та редагування контенту, а також автоматичне відстеження статусів через Google Sheets.

**Технології:** n8n, Groq LLaMA, Telegram Bot API, Google Sheets

## Project 2: Data Engineering — Hospital Data Pipeline
[Посилання](https://github.com/annayastremska/Hospital-Data-Pipeline)

Розробила наскрізний дата-пайплайн для медичної аналітики на базі Google Cloud: автоматизувала генерацію синтетичних даних та інкрементальний ETL через Apache Airflow, трансформувала сирі клінічні дані у 8 аналітичних мартів за допомогою dbt (73 пройдені тести) та підключила живий executive-дашборд у Looker Studio до BigQuery.

**Технології:** Google Cloud, Apache Airflow, dbt, BigQuery, Looker Studio

## Project 4: A/B Testing
[Посилання](https://app.notion.com/p/3642b79d794980159b6dd9bb0c4e25fe?source=copy_link)

Провела повний цикл A/B тестування функції нагадування про низький баланс: від формування гіпотези та розрахунку вибірки до статистичного аналізу результатів. Виявила статистично значуще зростання конверсії в першу оплату (+6,3%), проте на основі оцінки бізнес-ефекту та довірчих інтервалів рекомендувала не впроваджувати функціонал у продукт.

**Технології:** статистичний аналіз, A/B тестування, розрахунок вибірки

## Project 5: LTV Analysis
[Посилання](https://docs.google.com/presentation/d/1TsnkZg4fgsXA0M-7DEbFsrA3f-UcgNYfWATWeWQlNrc/edit)

Побудувала криву LTV (Lifetime Value) для когорт користувачів від дня реєстрації до 12-го місяця на основі даних про транзакції. Провела EDA з очищенням дублікатів та аномальних записів, визначила дві найкращі місячні когорти за LTV та проаналізувала причини їхньої ефективності через метрики ARPU, ARPPU, % платних користувачів та внесок топ-1% користувачів у виручку, а також вплив платформи й статі на дохід.

**Технології:** Python (pandas), когортний аналіз, LTV моделювання
